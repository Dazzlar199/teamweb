# 특별시 팀 대시보드

> **목적**: 특별시 팀 4명을 위한 내부 협업 도구  
> **기능**: 일정 공유, 작업 관리, 파일 공유, 이미지 업로드/다운로드

---

## 🚀 시작하기

### 개발 서버 실행
```bash
npm run dev
```

### 빌드
```bash
npm run build
```

### 배포 (Vercel)
```bash
# Vercel CLI 설치
npm i -g vercel

# 배포
vercel
```
