Chapter 01

프로젝트 개요

특별시 (The Special Time) 서비스 정의 및 비전

1.1. 서비스 정의

특별시 (The Special Time)는 AI 기반 웨딩 서브서비스 프리랜서 매칭 플랫폼으로, 예비부부와 웨딩 전문 프리랜서를 연결합니다.

One-Liner

"인생의 특별한 시간을 더 특별하게 - AI 기반 웨딩 프리랜서 매칭 플랫폼"

1.2. 브랜드 의미

요소 의미
특별시 (ㅌㅂㅅ) 인생에서 가장 특별한 시간(결혼식)을 더 특별하게 만드는 서비스
The Special Time 영문명으로 글로벌 확장 가능, 모든 특별한 순간을 위한 플랫폼
확장 비전 웨딩 → 경조사 → 기업행사 → All Events (TAM 15조원)

1.3. 핵심 가치

예비부부 (수요자)

  • AI 매칭으로 탐색 시간 99% 단축 (3주 → 3분)
  • 투명한 가격 정보
  • 에스크로 안전 결제
  • 검증된 프리랜서

프리랜서 (공급자)

  • 고정 수수료 (건당 최대 5,000원)
  • 숨고/크몽 대비 70% 비용 절감
  • 웨딩 특화 플랫폼
  • AI 추천 노출

1.4. 시장 규모

시장 규모 설명
웨딩 서브서비스 약 2조원 연간 19만 쌍 × 평균 100만원
웨딩 전체 시장 약 6조원 스드메, 예식장 포함
확장 시장 (경조사/이벤트) 약 15조원 Phase 2~4 확장 목표

프리랜서 매칭 + 웨딩 상품 마켓플레이스

2.1. 프리랜서 매칭 플랫폼

주요 기능

기능 설명 플랫폼
AI 스타일 매칭 포트폴리오 이미지 분석 → 스타일 유사도 기반 추천 Flutter 앱 + FastAPI
프리랜서 검색 카테고리, 지역, 가격 필터링 Flutter 앱
포트폴리오 갤러리 작품 이미지, 스타일 태그, 가격 정보 Flutter 앱 + Next.js 웹 (SEO)
실시간 채팅 예비부부 ↔ 프리랜서 견적 협상 Flutter 앱 (Supabase Realtime)
리뷰 시스템 별점, 텍스트 리뷰, 사진 리뷰 Flutter 앱 + Next.js 웹
에스크로 결제 서비스 완료 후 정산 (안전 결제) Flutter 앱 (토스페이먼츠)

웨딩 크루 시스템 (차별화 기능)

웨딩 크루

스냅+영상+축가+사회자 등을 팀으로 묶어 한 번에 매칭하는 패키지 서비스

  • 예비부부: 개별 섭외 시간 80% 절감, 통일된 스타일, 패키지 할인
  • 프리랜서: 교차 판매 기회, 협업 네트워킹
  • 특별시: 객단가 3배 증가

2.2. 웨딩 상품 마켓플레이스 (통합 예정)

상품 카테고리

카테고리 시장 규모 우선순위
청첩장 높음 Phase 1 (최우선)
답례품 높음 Phase 2
감사카드/초대장 중간 Phase 2
웨딩 소품 중간 Phase 2
웨딩 굿즈 낮음 Phase 3

주요 기능

  • 상품 등록/관리 (판매자 대시보드)
  • 카테고리별 탐색 및 검색
  • 장바구니 및 주문 관리
  • 맞춤 제작 옵션 (색상, 사이즈 등)
  • 상품 리뷰 및 평점
  • 결제 시스템 통합 (토스페이먼츠)
통합 전략

마켓플레이스는 완전히 독립된 모듈로 개발되어 기존 기능에 성능 영향을 주지 않습니다.

  • 기술 구현 난이도: 보통 (6/10)
  • 앱 속도 영향: 거의 없음 (모듈 분리)
  • 개발 기간: 2~3개월 (MVP 기준)

각 플랫폼의 역할과 기술 선택 이유

3.1. 전체 아키텍처

Frontend:
├── Flutter 3.x (iOS + Android 앱)
│   ├── Riverpod (상태관리)

Backend:
├── Supabase (70%)
│   ├── PostgreSQL (데이터베이스)
│   ├── Auth (JWT 인증)
│   ├── Storage (이미지/파일)
│   └── Realtime (채팅)
│
└── FastAPI (30%)
    ├── AI 처리 (이미지 분석, 매칭 알고리즘)
    ├── 결제 웹훅 처리
    └── 복잡한 비즈니스 로직

External Services:
├── OpenAI GPT-4o-mini (AI 상담, 키워드 추출)
├── Hugging Face CLIP (이미지 임베딩 - Phase 2)
├── 토스페이먼츠 (결제)
└── Vercel (Next.js 배포)

플랫폼 역할 주요 기능 배포

3.3. 데이터베이스 설계

핵심 테이블

  • users - 예비부부 정보
  • providers - 프리랜서 정보

  • matchings - 매칭/거래 정보
  • messages - 채팅 메시지
  • reviews - 리뷰
  • products - 마켓플레이스 상품 (신규)

기술 선택 이유
Flutter 단일 코드로 iOS/Android 동시 개발, 개발비 70% 절감
Next.js SEO 최적화 (프리랜서 프로필 검색 노출), Flutter Web 대비 우수
Supabase PostgreSQL + pgvector (AI 매칭 필수), 무료 티어 넉넉, 빠른 개발

8.1. AI 매칭 시스템

작동 방식

  1. 입력: 예비부부가 선호 스타일 선택 + 참고 이미지 업로드
  2. AI 분석:
    • 자연어 처리 (GPT-4o-mini): 스타일 키워드 추출
    • 이미지 임베딩 (CLIP): 참고 이미지 분석
    • 협업 필터링: 유사 고객 선호 반영
  3. 매칭: 포트폴리오 스타일 벡터 + 가격/일정 필터 + 리뷰 점수
  4. 출력: Top 5 프리랜서 + 매칭 점수
