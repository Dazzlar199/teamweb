Chapter 01

캐릭터 디자인 기초

1.1. 캐릭터 디자인의 핵심 원칙

좋은 캐릭터는 브랜드의 정체성을 시각적으로 전달하고, 사용자와 감정적 연결을 만듭니다.

원칙 설명 예시
단순성 기억하기 쉽고 재현하기 쉬운 형태 미키 마우스, 라인프렌즈
독특함 경쟁사와 차별화된 독특한 요소 카카오프렌즈의 개성
확장성 다양한 표정과 포즈로 확장 가능 다양한 상황별 활용
브랜드 일관성 브랜드 컬러와 톤앤매너 반영 특별시 컬러 (#B8860B, #18181B)
감정 전달 사용자와 공감할 수 있는 감정 표현 따뜻함, 친근함

1.2. 성공적인 캐릭터의 특징

1.2.1. 시각적 특징

  • 명확한 실루엣: 작은 크기에서도 식별 가능
  • 균형잡힌 비율: 과도하지 않은 디포르메
  • 색상 제한: 3-5색 이내 (인쇄/디지털 모두)
  • 라인 스타일: 일관된 선 두께와 스타일

1.2.2. 성격적 특징

  • 명확한 성격: 한 문장으로 설명 가능
  • 스토리: 캐릭터의 배경과 역할
  • 말투: 일관된 언어 스타일
  • 행동 패턴: 특징적인 제스처와 포즈

1.3. 캐릭터 디자인 프로세스

표준 디자인 프로세스
  1. 브랜드 분석: 브랜드 가치, 타겟, 경쟁사 분석
  2. 컨셉 개발: 키워드, 이미지, 스토리 개발
  3. 스케치: 다양한 아이디어 스케치 (50-100개)
  4. 선별: 팀 피드백으로 3-5개 선별
  5. 정교화: 선별된 안을 디지털로 제작
  6. 테스트: 다양한 크기/컨텍스트에서 테스트
  7. 최종 확정: 브랜드 가이드라인 문서화

1.4. 레퍼런스 및 영감

카테고리 캐릭터/브랜드 학습 포인트
글로벌 마스코트 미키 마우스, 라인프렌즈 단순함과 확장성, 오래 지속되는 디자인
국내 캐릭터 카카오프렌즈, 라인프렌즈, 모모 한국적 감성과 디지털 활용
웨딩/이벤트 웨딩 박람회 캐릭터, 이벤트 마스코트 업계 특성 반영, 고급스러운 이미지
AI/테크 ChatGPT, Microsoft Clippy (과거) 친근한 기술, 접근성

특별씨 캐릭터 개발

2.1. 특별씨 캐릭터 컨셉

항목 내용
이름 특별씨 (Teukbyul C)
역할 웨딩 가이드 AI 캐릭터, 브랜드 마스코트
성격 따뜻하고 친근하며, 웨딩 전문가 역할

외형 컨셉 친근하고 전문적인 이미지, 웨딩 테마 반영

컬러 사용 가이드
  • Primary (#18181B): 로고, 주요 텍스트, 라인
  • Accent (#B8860B): 강조, CTA 버튼, 캐릭터 악세서리
  • Accent Light (#D4AF37): 호버 상태, 그라데이션
  • Gray (#3F3F46): 보조 텍스트, 아이콘
  • Background (#FAFAFA): 배경색, 카드 배경
  • White (#FFFFFF): 밝은 배경, 로고 반전 버전

2.2.2. 비율 및 구조

캐릭터 비율 시스템 (2.5등신)

Head 1/3
Body 2/3

전체 높이 기준

헤드: 전체의 33% (큰 머리, 친근함)

신체: 전체의 67% (2.5등신 비율)

팔/다리: 신체의 50% 각각

눈 위치: 머리의 중간 지점

요소 비율 설명
전체 높이 100% 기준 높이
헤드 33% (1/3) 큰 머리로 친근함 표현
목 5% 헤드와 신체 연결
상체 30% 팔 포함
하체 32% 다리 포함
비율 원칙
  • 라인 스타일: 부드러운 곡선, 선 두께 2-3px (일관성)
  • 디테일: 최소한의 디테일 (작은 크기에서도 인식 가능)
  • 대칭: 정면 뷰는 대칭 유지, 포즈는 자연스러운 비대칭
  • 확장성: 16px부터 1024px까지 깨지지 않는 비율

2.2.3. 표정 시스템

표정 용도 특징
기본 (미소) 기본 상태, 인사 부드러운 미소, 따뜻한 눈
기쁨 성공, 축하, 긍정적 피드백 밝은 눈, 활짝 핀 입
설명 정보 전달, 가이드 차분한 표정, 손짓 제스처
공감 고민 상담, 위로 다정한 표정, 공감하는 포즈
진지 중요한 정보, 경고 차분한 표정, 신뢰감 있는 자세

2.3. 포즈 및 제스처

2.3.1. 기본 포즈

  • 인사: 손을 들어 인사하는 포즈
  • 안내: 손으로 가리키는 제스처
  • 설명: 두 손을 모으거나 설명하는 포즈
  • 축하: 박수 치는 포즈
  • 생각: 손을 턱에 대고 고민하는 포즈

2.4. 캐릭터 시트 (Character Sheet) 구성

필수 포함 요소
  • 프론트뷰: 정면, 측면, 후면
  • 표정 모음: 기본, 기쁨, 슬픔, 놀람, 화남 등
  • 포즈 모음: 자주 사용하는 포즈 10-15개
  • 크기 변형: 큰/중/작은 크기 버전
  • 컬러 변형: 컬러, 그레이스케일, 단색
  • 금지 사항: 하지 말아야 할 변형 예시

Chapter 03

벡터 그래픽 작업

3.1. Adobe Illustrator 활용

3.1.1. Image Trace (이미지 벡터화)

  1. 이미지 가져오기: File → Place (AI 생성 이미지)
  2. Image Trace 실행: Object → Image Trace → Make
  3. 프리셋 선택: "High Fidelity Photo" 또는 "3 Colors"
  4. 고급 옵션 조정:
    • Colors: 5-10 (컬러 수)
    • Paths: 90-100% (디테일)
    • Corners: 90-100% (각도)
  5. Expand: Object → Image Trace → Expand
  6. 수동 정제: Path 조정, 색상 통일, 라인 정리
