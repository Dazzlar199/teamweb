## 📊 2025년 예창패 핵심 정보 (기존 분석 자료 기반)

### 지원금액
- **평균 5,000만원** (최대 1억원)
- **자부담 0%** (전액 정부지원)

### 지원자격
- 공고일 기준 **사업자등록 없는 자**
- 3년 이내 폐업 이력은 통계용, 평가 반영 안 함

### 평가 기준 (4개 항목, 각 25점)
1. **문제인식** (25점) - 60% 미만 시 탈락
2. **해결방안** (25점) - 60% 미만 시 탈락
3. **성장전략** (25점) - 60% 미만 시 탈락
4. **팀구성** (25점) - 60% 미만 시 탈락

> ⚠️ **핵심**: 4개 항목 중 어느 하나라도 60% 미만(15점 미만)이면 무조건 탈락

### 평가 포인트 (서비스 플랫폼 기준)

| 항목 | 평가 포인트 | 주의사항 |
|------|------------|---------|
| **문제인식** | 고객 페인포인트 구체성, 시장 규모의 신뢰성 | 양측(고객+공급자) 문제 모두 제시, 실제 인터뷰 데이터 필수 |
| **해결방안** | 기술/서비스 차별성, 실현 가능성 | "매칭"만으론 부족 → AI/기술 차별화, MVP 필수 |
| **성장전략** | BM 수익성, 확장 가능성 | 콜드스타트 해결 전략, Unit Economics 필수 |
| **팀구성** | 관련 경험/역량, 실행력 증빙 | 도메인 전문가 필요, 기술 역량 증빙 |
