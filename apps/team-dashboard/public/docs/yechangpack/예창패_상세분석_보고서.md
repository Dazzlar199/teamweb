| **팀구성** | 25점 | 60% 미만 시 탈락 |

> ⚠️ **핵심!** 4개 항목 중 어느 하나라도 60% 미만(15점 미만)이면 무조건 탈락입니다.
> 균형 잡힌 준비가 필수입니다.

### 항목별 세부 평가 기준

#### 1. 문제인식 (25점)

| 평가 포인트 | 서비스 플랫폼 주의점 |
|------------|-------------------|
| 고객 페인포인트 구체성 | 양측(고객+공급자) 문제 모두 제시 |
| 시장 규모의 신뢰성 | 출처 명시, TAM/SAM/SOM 산출 근거 |
| 문제의 심각성/시급성 | 기존 해결책 한계 명확히 |
| - | **실제 인터뷰 데이터 필수** (최소 20명) |

**필수 포함 사항:**
- 고객 페인포인트 3개 이상 구체적 기술
- 실제 인터뷰 데이터 인용 (최소 20명)
- 시장 규모 (TAM/SAM/SOM) 출처 명시
- 기존 해결책 한계 분석

#### 2. 해결방안 (25점)

| 평가 포인트 | 서비스 플랫폼 주의점 |
|------------|-------------------|
| 기술/서비스 차별성 | "매칭"만으론 부족 → AI/기술 차별화 |
| 실현 가능성 | MVP 또는 프로토타입 필수 |
| 고객가치 명확성 | 경쟁사 대비 차별점 수치화 |

**필수 포함 사항:**
- 서비스 차별점 수치로 표현
- AI 매칭 로직 구체적 설명
- MVP/프로토타입 스크린샷 첨부
- 경쟁사 비교표 포함

#### 3. 성장전략 (25점)

| 평가 포인트 | 서비스 플랫폼 주의점 |
|------------|-------------------|
| BM 수익성 | 콜드스타트 해결 전략 명시 |
| 확장 가능성 | Unit Economics 필수 |
| 시장 진입 전략 | 네트워크 효과 설계 |

**필수 포함 사항:**
- Unit Economics (LTV/CAC) 산출
- BEP 달성 시점 및 근거
- 3년 재무계획 테이블
- 콜드스타트 해결 전략
- 시장 확장 로드맵

#### 4. 팀구성 (25점)

| 평가 포인트 | 서비스 플랫폼 주의점 |
|------------|-------------------|
| 관련 경험/역량 | 도메인 전문가 필요 |
| 역할 분담 명확성 | 기술 역량 증빙 (포트폴리오) |
| 실행력 증빙 | 팀 시너지 스토리 |

**필수 포함 사항:**
- 팀원 이력 및 역할 명시
- 도메인 전문성 증빙
- 기술 역량 포트폴리오
- 팀 스토리 (Why Us?)

## 🎯 서비스 플랫폼 특화 전략

### 서비스 플랫폼의 6대 도전과제

#### 도전과제 #1: 진입장벽 낮음
**문제점**: 앱 개발만으로는 경쟁사 진입을 막을 수 없음

**해결 전략:**
- AI 스타일 매칭 알고리즘 (자연어+이미지 임베딩)
- 데이터 해자: 웨딩 리뷰·포트폴리오 축적
- 특허 출원: AI 매칭 알고리즘 특허

#### 도전과제 #2: 양면시장 콜드스타트
**문제점**: 고객 없으면 프리랜서 안 오고, 프리랜서 없으면 고객 안 옴

**해결 전략:**
- 공급자 우선 확보 (CEO 네트워크 활용)
- 인센티브 설계 (첫 거래까지 무료)
- SNS 인기 프리랜서 집중 유치

#### 도전과제 #3: 높은 CAC, 낮은 초기 LTV
**문제점**: 고객 획득 비용은 높은데 초기 거래는 소액

**해결 전략:**
- LTV/CAC 8배 달성 (투자 기준 3:1 대비 우수)
- Blended CAC: 44,000원
- LTV: 352,000원 (가중평균)

#### 도전과제 #4: 네트워크 효과 달성까지 긴 시간
**문제점**: 임계 규모 도달 전까지 적자 지속

**해결 전략:**
- 버티컬 집중: 웨딩 서브서비스만
- 지역 순차 런칭: 서울·경기 → 지방
- 1년차 목표: 프리랜서 1,000명, MAU 10,000명

#### 도전과제 #5: 수수료 모델의 수익성 한계
**문제점**: 단순 매칭 수수료만으로는 마진 낮음

**해결 전략:**
- 3중 수익 모델:
  1. 매칭 수수료: 고정 1,000원/건
  2. 정산 수수료: 1,000~4,000원 (거래액 구간별)
  3. 구독 수익: Free/Basic/Pro/Premium

#### 도전과제 #6: 이탈 방지 어려움
**문제점**: 고객-프리랜서 직거래로 이탈

**해결 전략:**
- Lock-in 3중 방어:
  1. 플랫폼 내 에스크로 결제
  2. AI 포트폴리오 관리 툴
  3. 리뷰 자산화

### 평가위원이 반드시 묻는 질문

1. **"숨고/크몽과 뭐가 다른가요?"**
   → 웨딩 버티컬 특화, AI 스타일 매칭, 결혼준비 전체 여정 커버

2. **"콜드스타트는 어떻게 해결하나요?"**
   → CEO 업계 네트워크로 초기 50명 직접 섭외, SNS 인기 프리랜서 집중 유치

3. **"이탈 방지는요?"**
   → 플랫폼 내 에스크로 결제, AI 포트폴리오 관리, 리뷰 자산화

4. **"수익성 있나요?"**
   → 고정 수수료로 프리랜서 실수령 극대화, LTV/CAC 8배, 구독+매칭 믹스 수익

5. **"팀이 왜 이걸 해야 하나요?"**
   → 창업자의 웨딩 업계 경험/페인포인트 직접 경험 스토리

> **준비 TIP**: 위 5가지 질문에 대한 답변을 30초 내로 명확히 할 수 있어야 합니다.

```python
# PyPDF2 예시
import PyPDF2

pdf_file = open('공고문.pdf', 'rb')
pdf_reader = PyPDF2.PdfReader(pdf_file)
text = ""
for page in pdf_reader.pages:
    text += page.extract_text()
```
